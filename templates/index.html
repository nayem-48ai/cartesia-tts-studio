Frequently asked questions

What is TNxBD Studio?

A free AI text-to-speech (TTS) studio that turns text into natural MP3 audio using Cartesia's Sonic models — no signup or API key required.

Which languages are supported?

40+ languages including Bangla, English, Hindi, Spanish, French, Arabic, Japanese, Korean, Chinese, German, Portuguese, Russian, Italian and Dutch.

Is the text to speech service free?

Yes. TNxBD Studio is completely free to use from the web UI and offers a simple JSON API for developers.

Can I download the audio as MP3?

Yes. Every generated clip can be downloaded as a high-quality MP3 file with a single click.

Do I need an API key to use the TTS API?

No API key is required. Send a JSON POST to the /api/tts endpoint with language, model, voice_id and text to receive MP3 audio.

Can I generate Bangla (Bengali) text to speech?

Yes. TNxBD Studio includes natural Bangla TTS voices. Choose Bangla from the language list, pick a voice, type Bengali text, and generate a downloadable MP3.

Is there a Hindi TTS voice generator?

Yes. Hindi TTS is supported with clear male and female voices. Select Hindi, enter your text in Devanagari, generate the audio, and download it as MP3.

How do I use the TTS API?

Send a JSON POST to /api/tts with fields language, model, voice_id and text. The endpoint returns MP3 audio and needs no API key. Example requests are shown under the API section.

Can I use a custom voice model that isn't in the list?
