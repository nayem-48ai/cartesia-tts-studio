Questions

Is speech to text free?

Yes. Upload, live recording and realtime transcription are all free with no API key — the server uses the same free transcription flow as the TTS studio.

Which languages can it transcribe?

35 languages including Bangla, English, Hindi, Urdu, Arabic, Spanish, French, German, Japanese, Turkish and more. Pick the spoken language before transcribing for best accuracy.

Is there a size limit?

Each request accepts up to 4MB of audio (roughly a few minutes depending on format). For longer recordings, realtime mode transcribes chunk by chunk with no total limit.

How do I use the STT API?

POST an audio file as multipart form field file to /api/stt with language. You get JSON back with text, duration and optional word timestamps. A copy-ready example is in the Developer API box above.
